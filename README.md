# NRE TechOne Solutions website

A Next.js website built from the client-provided **WebPage Content-NRETechOne.pdf** and **NRE_TechOne_WhatsApp_Digital_Solutions.pptx**. The site has Home, About, Services, Solutions, Our Brands, Contact, and WhatsApp Solutions pages.

## Run locally

```bash
npm ci
npm run dev
```

Open <http://localhost:3000>. Run `npm run build` and `npm run lint` before publishing.

## Contact and inquiry behavior

The main contact email and location follow the PDF: `info@nretechone.com`, Bhopal, Madhya Pradesh. The WhatsApp number follows the deck: `+91 9340783663`. The inquiry form opens a draft in the visitor's email application; there is no server-side submission or storage. Confirm the email and WhatsApp account before release.

The PDF and deck contain different domains and email addresses. The site uses the main PDF for the company inbox and does not publish an uncertain website URL. Earlier contact details supplied in conversation differ from the attachments; the client-selected PDF details are now primary.

The two editorial photos in `public/assets` are illustrative generated imagery, not photos of NRE staff or client projects. Motion respects reduced-motion preferences.
