# NRE TechOne Solutions website

A responsive Next.js landing page for NRE's software development, mobile applications, web experiences, IT staffing, consulting, and digital marketing services.

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Run `npm run build` and `npm run lint` before release.

## Contact

The contact panel links to `info@nretech.com` and `320 154 1558` as provided by NRE. The phone number has no country code, so its `tel:` link uses the supplied digits only.

The logo asset is in `public/assets/nre-logo.jpeg`. The page uses NRE's stated services and original copy, with the service mix of the supplied reference site as inspiration. The decorative hero artwork is made with CSS and contains no external image dependency.
